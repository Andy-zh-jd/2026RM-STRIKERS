## 烧完怎么判断是"对的固件"

**现象级判据（3 条，全过才算成功）**

1. RGB 灯在变色（= TIM10 的 1 ms 中断活着）
2. 串口两行交替，各约 5 Hz：
   ```
   A：gx=.. gy=.. gz=.. ax=.. ay=.. az=.. aid=.. gid=.. serr=.. icnt=.. vbat=..
   B：m=.. tgt=.. cur=.. st=.. r1=.. r2=.. r3=.. r4=.. t1=.. t2=.. t3=.. t4=.. sL=.. sR=.. col=..
   ```
   > `DBG_MINIMAL 1` 下 IMU 那几个值是旧值/零，**这是预期的**
3. `vbat` 与实际供电相符：USB 供电 ≈ **4.10**，6S 电池 ≈ **25.9~26.1**

**二进制级判据（怀疑烧错版本时用）**

```powershell
$b=[IO.File]::ReadAllBytes("RM_Frame_C.bin")
"SP=0x{0:X8} Reset=0x{1:X8}" -f [BitConverter]::ToUInt32($b,0),[BitConverter]::ToUInt32($b,4)
```
本包固件应为：

```
SP    = 0x20020000      （SRAM 末尾，正确）
Reset = 0x08007555      （奇数 = Thumb 位正确；.isr_vector 在 0x08000000，长度 0x188）
bin   = 47 092 字节
```

## 烧完想立刻验证的三件事

1. **遥控**：SC 下档 → `sR=158`；右摇杆推上 → `col` 变正
2. **底盘单轮（M3 用）**：SB 拨下档（`sL=158`）→ 右摇杆 → 只有 **t1** 动、**r1** 跟着转，`t2~t4/r2~r4` 保持 0。
   要测右前轮，把 `ControlTask.cpp` 里 `ChassisSetWheelSpeed(0, ...)` 的 0 改成 1，重新编译烧录
3. **安全态**：拔掉接收机 → `st` 必须回到 **1**（电机不解锁）。若 `st=0`，说明 `RemoteAlive()` 被改坏了

## 烧录常见故障

| 现象 | 原因 / 处理 |
|---|---|
| `No available debug probes are connected` | ST-Link 驱动没装（`stsw-link009`）或线是充电线 |
| 串口 `ClearCommError / PermissionError 13` | 烧录把板子复位了、USB 重新枚举；烧前关串口，烧后等 2 s |
| 串口在、打不开（`Cannot configure port, OSError 22`）| 固件里有阻塞调用（IMU SPI 读）→ 换回 `DBG_MINIMAL 1` |
| 板子每 1.02 s 重启 | 看门狗没人喂（本包已改无条件喂）|
| 灯不亮 | SWD 是不是接了 5 V（会烧 IO）；或外设要 24 V 而只有 USB |

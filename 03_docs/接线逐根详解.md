# 接线逐根详解（从"这根线另一头插哪"开始）

> 原则：**一根线一根线加，加完测一次**。下面按"必须先接的"顺序排。

## 0. 先认三种接线语言

| 语言 | 怎么看 |
|---|---|
| **颜色** | 红 = 正极/5V；黑/棕 = 负极 GND；白/橙/黄 = 信号。CAN 特殊：**黑=CAN_L，红=CAN_H** |
| **公母** | 有针的是公，有小孔的是母。**公母不对就是插不进**（不是力气不够） |
| **防呆** | 有卡扣、有缺口、有方向。**插不进 = 方向错**，转 180° 或换端 |

## 1. 总览（八根线）

```
① 电池 ──滑入──► 电池架
② 电池架 XT60 ──转接──► C 板 24V IN (XT30)          【动力·粗】
③ C 板 24V OUT (XT30) ──► C620 的 XT30              【动力·粗】
④ C620 三相线 ──同色对接──► 电机三相线               【动力·粗】（第一步先不接）
⑤ C620 7-Pin ──► 电机 7-Pin                          【数据·细】
⑥ C620 CAN ──► C 板 CAN1（2 针）                     【数据·细】
⑦ 接收机 通道6 ──► C 板 DBUS 口                      【数据·细】
⑧ ST-Link ──► C 板 SWD（4 针）                       【数据·细】
⑨ C 板 micro USB ──► 电脑                            【数据·细】
⑩ 舵机 ──► C 板 PWM 排针（按 SERVO_ID_n）            【数据·细】
```

## 2. 逐根讲

### ① 电池 → 电池架
- 电池是**滑轨插入**的：对准电池架里的导轨，往里推到底，会有一声轻微的"到位"感
- 推完把**魔术扎带**绑上（防止冲击时弹出来）
- 电池架侧面有个**电源开关**，接完先保持关闭

### ② 电池架 XT60 → C 板 24V IN（XT30）
- 电池架输出是一根 **XT60**（两个大圆孔/两根粗针）
- C 板 24V 输入是 **XT30**（比 XT60 小一号）
- **所以需要一根 XT60↔XT30 转接线**（买或者自己焊，注意线径够粗）
- 插之前：**万用表蜂鸣档**测 XT30 两端，**不能响**（响了=短路）
- 极性：红线 → "+"，黑线 → "−"。C 板有防反接，但别指望它
- 上电顺序：先插好，再开电池架开关，最后长按电池开机

### ③ C 板 24V OUT → C620 的 XT30
- C 板上有 **24V OUT**（丝印 24V 或 POWER OUT），也是 XT30
- C620 的**电源输入**是一个 XT30（和电机三相线不在同一侧）
- ⚠️ 只给**一个电机**做台架测试时够用；**整车**必须走中心板 2 或分电板（C 板 24V OUT 不是给 20 A 用的）

### ④ C620 三相线 → 电机三相线（第一步先不接！）
- C620 出三根粗线，末端是**香蕉头（子弹头）**，颜色可能是黄/绿/蓝
- 电机侧也是三根，**同色对插**
- 三根顺序决定**转向**：反了就把**任意两根**交换
- **第一次调试不接这三根**（电机物理上转不起来，最安全）

### ⑤ C620 7-Pin → 电机 7-Pin（编码器，必接）
- 一根 7 芯细线，两端都是**带卡扣的小插头**，插错方向插不进
- 作用：把电机的**转子角度/转速**送进电调；**这条不接，串口里 `spd` 永远是 0**
- 听到"咔"一声才算插到底

### ⑥ C620 CAN → C 板 CAN1（2 针）
- C620 上标 `CAN` 的口，插入附带的 **CAN 线**
- CAN 线是 **2 芯**：`A = 黑 = CAN_L`，`B = 红 = CAN_H`
- C 板 **CAN1**（2 针座，注意不是旁边 4 针的 CAN2）：

  | C 板 CAN1 针位 | 接 |
  |---|---|
  | Pin 1 | **CAN_L（黑）** |
  | Pin 2 | **CAN_H（红）** |

- 接反**不会烧**，但一条数据都收不到 —— 表现就是"电调有电、就是不回数据"
- 1 Mbps 波特率已经在 `can.c` 里配好，**不用改**

### ⑦ 接收机 通道 6 → C 板 DBUS 口
- 接收机上：把**端口 6 设成 W.BUS**（遥控器菜单里设，见 `remotetask.md`）
- 从接收机**第 6 通道**的三针（信号 S / +5V / −GND）引出，插 **DBUS 线**
- DBUS 线另一端插 C 板丝印写着 **DBUS** 的 3 针位置（和 PWM 排针在同一块区域，见 `documents/graph/Cpwm.png` 左下角）
- 线序：**黑/棕 = GND，红 = +5V，白/橙 = 信号**
- ⚠️ 信号线和 5V 插反有可能烧接收机，**插之前对一下颜色**

### ⑧ ST-Link → C 板 SWD（4 针）
- C 板 J8 是 4 针小座（丝印 `SWD`）
- ST-Link 上有丝印：`3.3V` `SWDIO` `SWCLK` `GND`（克隆版可能是 `3V3` `DIO` `CLK` `GND`）

  | ST-Link | → | C 板 SWD |
  |---|---|---|
  | 3.3V | → | 3.3V（第 4 针）|
  | SWDIO | → | SWDIO（第 1 针）|
  | SWCLK | → | SWCLK（第 2 针）|
  | GND | → | GND（第 3 针）|

- ⚠️ **绝对不接 5V** —— 会打穿 STM32 的 IO。ST-Link 上如果有 5V 针，空着
- 顺序不用慌：接错 SWDIO/SWCLK 只是连不上，不会烧

### ⑨ C 板 micro USB → 电脑
- 注意是 **micro USB**，不是 Type-C（Type-C 在裁判系统模块上）
- 必须是**数据线**：插上后设备管理器里应出现 `STM32 Virtual ComPort`

### ⑩ 舵机 → C 板 PWM 排针
- 舵机是 3 芯：`棕/黑 = GND`、`红 = +5V`、`橙/白 = 信号`
- 按 `SERVO_ID_n` 插到对应针位（`documents/graph/Cpwm.png` 标了 1/2/4/7 的位置）
- 排针上的 5V 来自 **VCC_5V_M**，7 路总输出 5 A —— 6 个舵机同时发力可能不够，出问题再考虑外接 UBEC

## 3. 上电前必做的 5 项检查

| # | 检查 | 怎么做 |
|---|---|---|
| 1 | **短路** | 蜂鸣档测电源正负极，**不响** |
| 2 | **极性** | 红线对 +，黑线对 −（对着万用表读数正负验证）|
| 3 | **紧固** | 7-Pin 有"咔"声、XT30 推到底、CAN 插头卡扣扣上 |
| 4 | **绝缘** | 裸露的线头不能碰到金属底盘 |
| 5 | **开关状态** | 电池架开关关、电池关机，才开始接线 |

## 4. 分阶段接线顺序（照这个顺序加）

| 阶段 | 接哪几根 | 加完该看到什么 |
|---|---|---|
| 1 | ⑨ 只接 USB | 灯变色 + 串口有数据 |
| 2 | ⑧ ST-Link | `pyocd list` 看到探针、能烧录 |
| 3 | ①② C 板单独上电池 | 灯还变色、`vbat=` 有读数 |
| 4 | ③⑥⑤ **不接④** | 手转电机轴，`spd/ang` 变 |
| 5 | ④ 三相线 | 才可能真转（**先固定电机**）|
| 6 | ⑦ 接收机 | 拨档位/推杆，`sL/sR/col` 变 |
| 7 | ⑩ 舵机 | 关节能动，急停断电 |

**任何一步失败，退回到上一步**——上一步是好的，问题就在新加的这根线上。

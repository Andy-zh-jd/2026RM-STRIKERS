## 阶段 1 · 机械（先机械，后电气）

### 1.1 电机装底盘

| 位置 | 电机 | ID | 备注 |
|---|---|---|---|
| 左前 | M3508 | **1** | `CMFL` |
| 右前 | M3508 | **2** | `CMFR` |
| 左后 | M3508 | **3** | `CMBL` |
| 右后 | M3508 | **4** | `CMBR` |

**装之前在每个电机外壳上贴标签**（1/2/3/4），装上去之后就看不清了。

### 1.2 麦轮安装（最容易装错，直接导致斜着走）

**从车顶往下看，四个轮子的辊子必须呈 X 形（都指向车体中心）：**

```
       左前 ↘   ↙ 右前        辊子方向示意（俯视）
          ╲   ╱
          ╱   ╲
       左后 ↗   ↖ 右后
```

**检查方法**：从上往下看，四条"辊子脊线"应该**交于车体中心附近**。
如果某个轮子看起来是 `→→→` 顺着走的，说明**装反了或者装错了侧**。

**检录要求**：麦轮最外侧晃动 **< 1 mm**（用手晃轮子边缘测）。

### 1.3 电调就位

四个 C620 **靠近各自电机**固定（减少三相线长度），但**不要贴着电机**（电机发热）。
线缆出口朝车体内侧，方便走线。

## 阶段 2 · 电源骨架（先规划，再接线）

### 2.1 供电链路（规则硬要求，检录必查）

```
电池 → 电池架 → 裁判系统电源模块 → 分电
                                      ├─ 中心板2 → 4× C620 的 XT30
                                      └─ C 板 24V IN
```

⚠️ **电池的 24 V 必须先过裁判系统**，不允许"电池直接接电调"。检录会查，不合规会被要求整改。

### 2.2 位置安排

| 部件 | 位置建议 |
|---|---|
| 电池架 | 车体中部偏后，重心居中，方便插拔 |
| 裁判系统电源模块 | 靠近电池架，线越短越好 |
| 中心板2 | 底盘中心，四个电调呈放射状 |
| C 板 | 底盘上层，**SWD/USB 口朝向侧面**（方便插线）|

### 2.3 主线规格

- 电池 → 裁判系统：**原装线**，不要延长
- 裁判系统 → 分电：≥ 14 AWG
- 分电 → 单个 C620：XT30 原装线足够（单轮峰值 ~10 A）

## 阶段 3 · 接线顺序（**严格按这个顺序，全部断电操作**）

> 原则：**先信号，后动力**。动力线最后接，接完直接上电测试。

### ① CAN 总线（最先接）

- 一条总线串起：**C 板 CAN1 → C620#1 → #2 → #3 → #4**
- 线序：`CANH - CANH`、`CANL - CANL`（C 板 CAN1：**Pin1 = CANL，Pin2 = CANH**）
- **终端电阻：只有两端的节点开 120 Ω**（C 板端 + 最远的那个 C620），中间两个 **关闭**
- 接完用万用表测：CANH-CANL 之间电阻 ≈ **60 Ω**（两个 120 Ω 并联）

### ② 编码器线（7-Pin）

- M3508 尾部 → 对应 C620 的 7-Pin 口
- **线越短越好，不要盘圈**（编码器信号怕干扰）
- 插到底，听到/感觉到卡扣到位

### ③ 电调电源

- 中心板2 的四路输出 → 四个 C620 的 XT30
- **接之前确认每路极性**（红正黑负），反接会烧电调

### ④ 三相动力线（最后接）

- M3508 → C620，**同色对插**
- **任意对调两根可反转** —— 先按同色接，方向不对再调线或在代码里翻符号
- 三相线是**最粗、干扰最大**的线，走线要单独规划（见阶段 4）

## 阶段 4 · 理线规范（8 条）

### 4.1 分层原则

```
上层：信号线（CAN、编码器、DBUS、SWD）
─────────────────────────────
下层：动力线（24V 主干、三相线）
```

**三相线和信号线并行距离不超过 10 cm**，必须交叉时**垂直交叉**（不要平行贴一起）。

### 4.2 八条铁律

1. **两头贴标签**：`FL` `FR` `BL` `BR`、`CAN-H` `CAN-L`、`24V` `GND`
2. **每 10 cm 一个扎带固定点**，扎带尾巴剪平（避免划手/勾线）
3. **接头处留松弛弧**（2~3 cm），不要让线绷紧受力
4. **多余长度盘成 S 形**，**不要打圈**（打圈 = 电感，会产生干扰）
5. **过孔/锐边加护线圈或缠胶带**
6. **接收机天线朝上**，离金属件和动力线 **≥ 5 cm**（2.4G 怕遮挡）
7. **C 板的 USB/SWD 口保持可插拔**（调试口不能被绑死）
8. **所有线不能悬空晃**（比赛震动会导致接头松动）

### 4.3 走线走向（俯视示意）

```
   ┌──────────────────────────────┐
   │  [C板]        [接收机天线↑]   │  ← 上层：信号
   │    │                          │
   │  CAN 总线 ────┬────┬────┬────┐│  ← 沿车体一侧走
   │              #1   #2   #3   #4│
   │  ┌────────────────────────┐  │
   │  │  24V 主干（贴底板边缘）  │  │  ← 下层：动力
   │  └────────────────────────┘  │
   │   三相线分别就近连到各 C620    │
   └──────────────────────────────┘
```

## 阶段 6 · 架空测试与方向修正

### 6.1 测试动作

```
1. 四个轮子离地（车倒扣或架起来）
2. SC 拨上档（非急停）
3. SB 拨上档（底盘模式，sL=97）
4. 右摇杆【向前推】→ 四个轮子应该都"向前滚"
```

### 6.2 方向修正表

| 现象 | 原因 | 修法 |
|---|---|---|
| 某一个轮子反转 | 三相线相序 | 对调该电机任意两根三相线 |
| 四个轮子全反转 | 代码符号 | `ChassisSetVelocity` 的 vx 取反 |
| 前进时斜着走 | **麦轮装反/装错侧** | 拆下来按 X 形重装 |
| 前进正常、平移反了 | 逆解符号 | 代码里 `vy` 取反 |
| 数值差异 > 20% | 该轮阻力大/ID 错/减速比 | 单独查该轮 |

### 6.3 急停验证（必做）

**SC 拨到下档** → 四个轮子**立即停**，`cst` = 1。

## 常见故障速查

| 现象 | 最可能原因 | 查什么 |
|---|---|---|
| 某个电调绿灯闪的次数不对 | ID 没设好 | 重新设 ID |
| `r1~r4` 全是 0 | CAN 线序反了 / 终端电阻没开 | 万用表测 CANH-CANL ≈ 60 Ω |
| 只有一个轮子有数据 | 该电调 7-Pin 没插到底 | 重新插 |
| 推杆有 `ctgt` 但轮子不转 | 三相线没接 / 电调过流保护 | 查三相线、听电调有没有异响 |
| 电调上电红灯闪 2 次 | 三相线未接入 | 接好三相线 |
| 电调橙灯闪 2 次 | 总线上有重复 ID | 重新设 ID |

# 代码架构详解（RM2027_School_Comp_Frame）

> 目标：读完这一份，你能回答"上电后发生了什么""这一毫秒里发生了什么""我要改的东西该插在哪"。
> 所有行号对应当前仓库版本（2026-10-20）。

## 0. 一句话

`main()` 只跑一次做初始化；之后**每 1 毫秒**由 TIM10 中断把 4 个函数按固定顺序跑一遍；`while(1)` 永远空转。

## 1. 启动时序（上电 → 开始跑）

```
上电复位
 ↓
SystemInit（时钟初始化，168 MHz）      startup/startup_stm32f407xx.s
 ↓
C++ 全局对象构造                        ← 注意！在 main() 之前
    Motor CMFL/CMFR/CMBL/CMBR          构造函数体里完成"注册"
    Motor UserMotor
    PID_Regulator_t / MOTOR_INIT_t 等
 ↓
main()                                  Device.cpp:233
    ① HAL_Init()
    ② SystemClock_Config()              168 MHz
    ③ MX_*_Init()  × 16                  GPIO/DMA/TIM5/TIM1/TIM4/TIM10/TIM8
                                          ADC1/ADC3/USART1/6/3/CAN1/CAN2/I2C3/SPI1/2
    ④ HAL_TIM_Base_Start_IT(&htim5) + 3 路 PWM 启动（RGB 灯）
    ⑤ RemoteControl::init()             USART3 DMA + 空闲中断
    ⑥ bsp_flash_read()                  读 Flash 里的校准数据
    ⑦ HAL_TIM_Base_Start_IT(&htim10)    ★ 1 ms 时基开始跳
    ⑧ Motor::Init()                     CAN 启动 + 开接收通知 + 滤波器
    ⑨ ChassisStart() / UserInit()        IMU 标定（约 1.1 s，循环里喂狗）
    ⑩ init_Flag = 1                     ★★★ 中断里的逻辑从此才真正执行
 ↓
while(1) { }                            ★ 空的，所有事在中断里
```

**为什么先在 ⑦ 启动 1 ms、⑩ 才放开逻辑**：`HAL_TIM_PeriodElapsedCallback` 第一行就是 `if (init_Flag == 0) return;`。这样即使中断先跑起来，也不会在初始化没完成时去动电机——**这是框架里最重要的一个安全设计**。

## 2. 中断地图（谁在什么时候打断谁）

| 中断 | 优先级 | 谁在用 | 做什么 |
|---|---|---|---|
| `TIM1_UP_TIM10` | — | TIM10 | **1 ms 主循环**（全车控制）|
| `TIM1_UP_TIM10` | — | TIM1 | 50 Hz 舵机时基（在回调里被 `htim == &htim10` 过滤掉）|
| `CAN1_RX0` / `CAN2_RX0` | 0 | 电调回传 | `HAL_CAN_RxFifo0MsgPendingCallback` → `Motor::IT_Handle()` |
| `USART3` | 0 | 遥控器 | 手写在 `RemoteControl.cpp:145`，处理 DMA 双缓冲 + 空闲中断 |
| `DMA1_Stream1` | — | USART3 的 DMA | 搬 25 字节遥控帧 |
| `EXTI0` | — | 板载 KEY（PA0） | 切灯的速度档 |
| `OTG_FS` | — | USB CDC | 串口打印 |
| `USART1` / `USART6` | 8 | 预留（裁判系统等）| 空 |

**关键点**：CAN 接收是**中断驱动**（数据一到就存进 `feedback`），而 PID 和发包是**1 kHz 轮询**（每毫秒算一次）。两者节奏不同，靠 `feedback` 这个共享变量衔接。

## 3. 三个时间基准（都由定时器决定）

| 定时器 | PSC | ARR | 结果 | 用途 |
|---|---|---|---|---|
| TIM10 | 168-1 | 1000-1 | 168 M / 168 / 1000 = **1 kHz（1 ms）** | 全车控制周期 |
| TIM1 / TIM8 | 168-1 | 20000-1 | 1 M / 20000 = **50 Hz** | 舵机 PWM（500–2500 µs）|
| TIM5 | 0 | 65536-1 | — | RGB 灯（3 路 PWM 调亮度）|

## 4. 类结构

```
Device（抽象基类，Device.h:62）
  ├─ protected: deviceType, deviceID
  ├─ virtual void Handle() = 0;        ← 每周期必须实现
  └─ virtual void ErrorHandle() = 0;
        ↑
        ├── Motor      （private 继承，273 行）
        ├── RemoteControl（静态工具类，148 行）
        └── Servo      （104 行）
```

### Motor（最重要的类）
```cpp
class Motor : private Device {
    static Motor* motorPtrs[2][8];     // 2 条 CAN × 8 个位置  → 收帧时按 StdId 找对象
    static int16_t motor_intensity[16]; // 16 个电机的电流值    → 发帧时按位置取
    static uint32_t motor_IDs;          // 位图：哪些位置有电机 → 决定发哪几帧
    uint8_t stopFlag{1};                // ★ 默认 1 = 不输出（安全默认）
    C6x0Rx_t feedback;                  // 从 CAN 收到的原始值
    PID speedPID, anglePID;
    MOTOR_STATE_t state;                // 换算后的物理量（速度/角度/温度）
    ...
};
```

| 方法 | 什么时候被调 | 干什么 |
|---|---|---|
| `Motor(uint32_t id, MOTOR_INIT_t*)` | **main() 之前**（全局对象构造）| 把自己登记进 `motorPtrs`，复制 PID 参数，`targetSpeed = 0` |
| `static Init()` | main 里一次 | `HAL_CAN_Start` ×2、开 RX 通知、配滤波器（全通）|
| `Handle()` | 每 1 ms（由各 Task 调）| 更新速度 → 算 PID → 写入 `motor_intensity`（`stopFlag==1` 写 0）|
| `SetTargetSpeed()` / `SetTargetAngle()` | 你的逻辑里 | 设目标 + **清 stopFlag**（这是"允许输出"的开关）|
| `Stop()` | 急停 | `stopFlag = 1` |
| `static CANPackageSend()` | 每 1 ms 最后一步 | 把 `motor_intensity` 拼成 8 字节 → 发 `0x200`/`0x1FF` |
| `static IT_Handle(hcan)` | CAN 接收中断 | 按 `StdId-0x201` 找到对象 → 写 `feedback` |

### Servo
- `servoInfo[7]` 把 `SERVO_ID_1..7` 映射到 7 个定时器通道（TIM1 CH1-4、TIM8 CH1-3）
- `SetTargetAngle()`：先开 PWM，再做软件限位 `INRANGE(angle, min, max)`，最后存目标
- `Handle()`：`duty = AFFINE(0,180, 0.025,0.125, angle)` → `CCR = ARR * duty`（即 500–2500 µs）
- `stop()`：关掉该通道 PWM（急停时舵机断电）

### RemoteControl（纯静态，无实例）
- `init()`：USART3 开 DMA 循环模式 + 空闲中断
- `sbus_to_rc()`：25 字节里按位拼出 8 个 11 位通道（`sbus_buf[1] | sbus_buf[2]<<8` 这类位运算）
- 通道 → 物理量的换算：减 1024 偏移，除 671 → **-1 ~ 1**；开关直接取原始值当枚举
- `rcInfo` 是全局唯一的"当前遥控状态"

    //   ChassisStopFlag==0 时调 WheelsSpeedCalc()  ← 麦轮逆解

    UserHandle();        // ③ UserTask.cpp:233

## 6. 四条数据流

**① 遥控（人 → 车）**
```
接收机 → USART3 → DMA(双缓冲) → 空闲中断 → RemoteControl::ITHandle()
  → this_time_rx_len == 25 时 → sbus_to_rc()
  → rcInfo.{left_col,right_rol,sLeft,sRight,...}
```

**② 控制（目标 → 电流）**
```
rcInfo → CtrlHandle() → ChassisSetVelocity(vx,vy,ω)
  → WheelsSpeedCalc()   k=(0.40+0.38)/2=0.39
      FL = vx - vy - kω ; FR = vx + vy + kω
      BL = vx + vy - kω ; BR = vx - vy + kω      （单位 m/s）
  → ÷(WHEEL_DIAMETER/2) → rad/s → RADpS2RPM → 目标输出轴 RPM
  → Motor::SetTargetSpeed()  （清 stopFlag）
  → Motor::Handle() → PIDCalc(target, state.speed) → motor_intensity[i]
```

**③ 发送（电流 → 电机）**
```
motor_intensity[0..3] → 8 字节 → CAN1 0x200 → C620(ID1-4)
motor_intensity[4..7] → 8 字节 → CAN1 0x1FF → C620(ID5-8)
（CAN2 同理，ID9-16）
每个 int16 高字节在前：canBuf[2i] = v>>8; canBuf[2i+1] = v;
```

**④ 回传（电机 → 车）**
```
C620 → 0x201~0x208 → CAN1_RX0 中断 → HAL_CAN_RxFifo0MsgPendingCallback
  → Motor::IT_Handle() → motorPtrs[can][StdId-0x201] → feedback.{angle,speed,moment,temp}
  → 下一毫秒 MotorStateUpdate():
       state.speed = feedback.speed / reductionRatio   (19.2032)
       state.angle 用差值累积（8 位量化 + 跨零点处理）
```

## 8. 五个必须知道的陷阱

1. **`stopFlag` 默认 1**：没调 `SetTargetSpeed()` 的电机电流恒 0。想让它动，必须调一次。
2. **`MOTOR_INIT_t._motorID` 对实例无效**：`Motor UserMotor(MOTOR_ID_5, &init)` 用的是**构造参数**，结构体里写的 `_motorID` 会被覆盖。
3. **PID 积分不乘 dt**（`errSum += err`），1 kHz 下积分速度是常规写法的 1000 倍 → `ki` 量级 **0.1~1.0**；且 `ki` 与 `componentKiMax` 必须一起改，否则积分被限幅压成 0。
4. **TIM1 和 TIM10 共用一个中断向量**：所以回调里必须 `if (htim == &htim10)`，否则舵机时基会被当成控制周期。
5. **全局对象在 main 之前构造**：别指望 main 里的顺序影响注册顺序；也不要为了"晚点注册"把 Motor 改成指针。

## 9. 你要加东西，只动三个地方

```cpp
// ① 声明（UserTask.cpp 顶部）——构造函数自动注册
Motor Gripper(MOTOR_ID_5, &gripInit);

// ② 初始化 + 每周期调用（UserTask.cpp）
void UserInit()   { /* 必要的初始化 */ }
void UserHandle() { Gripper.Handle(); }

// ③ 给目标（ControlTask.cpp 的某个档位）
Gripper.SetTargetSpeed(100);      // 自动清 stopFlag

// ④ 急停（UserStop 里）
Gripper.Stop();
```

**不要做**：把逻辑写进 `while(1)`（它空转）；改 `Src\*.c`（CubeMX 会覆盖）；在中断里做耗时操作（USB 打印、等 ADC）。

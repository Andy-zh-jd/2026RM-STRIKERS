
## 二、🔴 曾经踩的坑：位掩码 vs 普通数字（浪费约 1 小时）

框架里 `GET_MOTOR_POS(ID) = log2(ID)`，而 `MOTOR_ID_1..8 = 0x01, 0x02, 0x04, 0x08…`

| 写法 | 实际注册到 | 后果 |
|---|---|---|
| `ID_WHEEL_FR = 4` | `log2(4)=2` → = MOTOR_ID_3 的槽 | 右前抢了左后的槽 |
| `ID_WHEEL_FR = 3` | `log2(3)=1.58→1` → = MOTOR_ID_2 的槽 | 和右后抢槽 → **`a2` 恒 0**，误判成"电调坏了" |

**排查技巧**：某个槽恒 0 而其它槽有数时，先怀疑"两个 Motor 对象注册到了同一个槽"，
而不是马上怀疑硬件。这次就是靠 `g_dbg[14] = rx203 收帧计数`（SWD 读，不经过 USB）
证明"帧一直在到（≈1000 帧/秒）"，才把锅从硬件翻回软件。

## 三、怎么测（当前固件 `CHASSIS_TEST_MODE 1`）

⚠️ 上电前：**轮子悬空**；急停随时可按（SC 拨下档）。

| SC（右三段） | SB（左三段） | 选中 | `wi` |
|---|---|---|---|
| 上（97）| 上（97）| 左前 | 0 |
| 中（0）| 上（97）| 右前 | 1 |
| 上（97）| 中/下 | 左后 | 2 |
| 中（0）| 中/下 | 右后 | 3 |

**右摇杆上下**给转速：满杆 = ±30 rpm（输出轴）。中位 ±8% 死区。

## 四、单轮通过判据（三条全过）

1. **`a` 是 0~8191 之间的数**（有帧）
2. **`t` 有数、`r` 同号**跟着变（能转、方向一致）
3. **耳朵/眼睛**：转得顺、没咔哒声

方向要**记下来**：正目标时轮子是朝"车前进"还是"车后退"，四轮凑齐后一起校符号。

## 六、常见故障对照

| 现象 | 可能原因 | 先查什么 |
|---|---|---|
| `a` 恒 0、其它三个有数 | **两个对象抢同一个槽**（ID 写成普通数字）| 用 `MOTOR_ID_x` 常量；或看 `g_dbg[14]/[15]` 有没有帧 |
| `a` 有数、`r` 恒 0 | 三相线没插 / 欠压 / 电调保护 | C620 灯：红灯每秒闪 2 次 = 三相线未接入 |
| 橙灯每秒闪 2 次 | **两个电调同 ID** | 改一个的 ID（SET 长按 → 短按 N 次 → 断电重上）|
| `r` 与 `t` 反号 | 电机方向 | 记下来，四轮一起改符号 |

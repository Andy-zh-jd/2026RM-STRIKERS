# M3 · 逐轮验收表

> 目标：四个轮子**逐个**确认「CAN 通 / 电调 ID 对 / 能转 / 方向对」。
> **调参（PID）不在这一步做**——等整车装好、四轮都上了再统一调。

## 怎么测（当前固件 `CHASSIS_TEST_MODE 1`）

⚠️ 上电前：**轮子必须悬空**（车垫起来），急停随时可按（SC 拨到下档）。

| SC（右三段） | SB（左三段） | 选中 | 电调 ID | 串口 `wi` |
|---|---|---|---|---|
| 上（97）| 上（97）| 左前 CMFL | 1 | 0 |
| 中（0）| 上（97）| 右前 CMFR | 2 | 1 |
| 上（97）| 中/下 | 左后 CMBL | 3 | 2 |
| 中（0）| 中/下 | 右后 CMBR | 4 | 3 |

**右摇杆上下**给转速：满杆 = ±30 rpm（输出轴）。中位 ±8% 死区。
串口看两个数：`t{轮子}` = 目标，`r{轮子}` = 实测。

## 单轮通过判据（三条全过）

1. **`t` 有数**：推杆时目标跟着变（说明代码路径通）
2. **`r` 同号**：实测跟着变、符号与目标一致（说明 CAN + 电调 ID + 反馈都对）
3. **耳朵/眼睛**：转得顺、没有咔哒声、没有原地抖动

方向是否正确要**记下来**（正目标时轮子应该朝"车往前开"的方向转）；四个轮都测完后一起校符号。

### ✅ 已改为“代码绑定”，不用碰 C620 的 SET 键（2026-10-23）

C620 的 `SET` 是个 3~4 mm 的小按钮，改 ID 麻烦。框架里的 `CMFL/CMFR/CMBL/CMBR`
只是**对象名**，绑哪个电调 ID 由 `ChassisTask.h` 里这张表决定。

**实测确认的对应（用手转轮子看哪个 `aN` 在变 —— 这是唯一可信的方法）：**

| 物理轮 | 电调 ID | 帧槽 `aN` | 状态 |
|---|---|---|---|
| 左前 | 1 | `a1` | ✅ 已验证（能转、同号）|
| **右前** | **3** | `a2` | ❌ **`a2=0`，该电调 CAN 不通**（灯正常闪 3 下 = ID 对、供电对）|
| 左后 | 4 | `a3` | ✅ 已验证（`a3=3009`，手转变化）|
| 右后 | 2 | `a4` | ✅ 能转（`a4=3530`） |

> ⚠️ **不要用 LED 闪数推"哪个轮子"**。LED 只说明"这个电调的 ID"，
> 而"它驱动哪个轮子"取决于电机线（7 芯 + 三相）插在哪个电调上。
> 实测踩过这个坑：按 LED 推出来的左右后是反的，白折腾半小时。

```c
#define ID_WHEEL_FL   1u     /* 左前 */
#define ID_WHEEL_FR   3u     /* 右前 */
#define ID_WHEEL_BL   4u     /* 左后 */
#define ID_WHEEL_BR   2u     /* 右后 */
```

### 🔴 当前唯一阻塞：右前（ID3）的 CAN 不通

| 已排除 | 依据 |
|---|---|
| 供电 | LED 绿灯每秒闪 3 下 = ID 正确、供电正常 |
| ID 冲突 | 橙灯不再出现，四路 ID 互不相同（1/2/3/4）|
| 代码绑定 | 其它三个 `a` 槽都归位了，`a2=0` 是"没帧"而不是"绑错" |

**待做**：把 ID3 电调接到左前那根已知好的 CAN 线 + 电源上
- `a2` 有数 → 是右前位置的 CAN 线/分支/插头坏
- `a2` 仍 0 → **该电调 CAN 收发损坏**，需要借一个 C620（M3508 的 C620 与 M2006 的 C610 不能互换）

改完重烧即生效，**逆解和方向约定都不用动**。硬规则两条：
1. 四个 ID 必须互不相同（同 ID 会撞车：橙灯闪 2 次 + 输出关闭）
2. 不要用 ID 5（0x1FF 帧被 M2006 占了）

> 串口的 `tN / rN / aN` **一律按物理位置编号**（1=左前 2=右前 3=左后 4=右后）。
> 改完绑定后 `a3=5874`（左后）回到正确槽位，`a2=0`（右前未接）—— 说明表对了。

> **`aN`（A 行）= 该电调反馈帧里的转子角度（0~8191）**：一直是 0 → 没帧（CAN/供电/ID）；
> 是正常数字 → 帧在到达。它比 `r` 更早暴露问题：`r=0` 可能只是没转，`a=0` 是没通信。
> 左手转电机轴时 `aN` 会明显变化，这是最快的判据。

## 常见故障对照

| 现象 | 可能原因 | 先查什么 |
|---|---|---|
| `t` 有数、`r` 恒 0 | CAN 没通 / 电调没供电 / **ID 设错** | C620 灯闪几次（闪 N 次 = ID N）；24 V 到没到电调 |
| 推杆没反应、`t` 也 0 | 选轮组合不对 / 不在测试模式 | 看 `wi` 和 `sL`/`sR` |
| `r` 正负和 `t` 反着来 | 电机方向（线序/安装方向） | 记下来，四轮一起改符号 |
| 电机只嗡一下停 / 红灯闪 | 三相线没接好 / 过流 / 欠压 | 三相线插紧、电池电压 |
| 抖、咔哒、转速上不去 | 机械干涉 / 轮子没固定 / 纯 P 静差 | 先看机械，别急着调 PID |

## 下一步（四轮都打勾之后）

1. 四个轮子一起垫空转（同一个 `t`，看四个 `r` 是否同号同向）
2. 落地走 2 m 直线（先 `CHASSIS_TEST_MODE 0`，SB 上档正常驾驶）
3. **此时才调 PID**：从 `kp=120, ki=0` 起步，加 `ki=0.05 / componentKiMax=1500`；
   在 60~100% 额定转速上调，别在 3% 额定转速（8 rpm 输出 ≈ 转子 154 rpm）上调——
   那个区间摩擦/齿槽主导，任何 PID 都会抖。

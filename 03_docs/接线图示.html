1. 今晚卡住的地方：C 板 24PIN 排针的行列

手册 P.14 的 PWM 原理图给出了关键信息，这是整页最有价值的一张：

从原理图能直接读出来的三行：
· A1 ~ A8 全部连到 PGND（地）
· B1 ~ B8 全部连到 VCC_5V_M（5V） —— 就是这个电压供给 DBUS/舵机
· C1 ~ C7 是 7 路 PWM 信号，C8 是 DBUS 信号（经 R134 4.7K 接到反相电路 → USART3）

所以 3 针插头必须“竖着”跨 A-B-C 三排

这解释了今晚的所有现象：接收机灯不亮（没 5V）、sL/sR/col 恒 0（没信号）。
因为 24V 已经正常（vbat=26、拔掉 USB 灯还在跑），所以问题几乎肯定在这个插头的方向/接触，而不是板子。
⚠️ 2026-10-20 追加更正（以手册 P.5 接口图为准）：
C 板上 DBUS 是一个独立的小 3 针口（P.5 图上编号 16，就在丝印 5V / DBUS 旁边），不是插进下面那排 8×3 的 PWM 排针（编号 15）。
上面这套「A/B/C 三排」的说明只适用于接舵机的 PWM 口。接遥控器 → 插 16 号那个专用口。
因此排查重点变成：① 是否插在 16 号口 ② 16 号口三针的公母/顺序（看丝印，红线对 5V）③ 那根线是不是交叉线 ④ 接收机是否已损坏。

另外两个要一并核对的东西

检查正确做法错了会怎样
排针间距C 板是 1.25 mm（Molex PicoBlade，手册型号 1.25T-7-4AW）；对插的插头必须也是 1.25 mm用 2.54 mm 舵机头硬插：看着进去了，实际中间那根针（5V）没接触
C 板 24V 口插 24V IN插成 24V OUT：输入保护电路不工作，5V 那一路可能起不来

C610 反馈帧（手册 P.9）

字节内容说明
DATA[0..1]转子机械角度0 ~ 8191（一圈 360°）
DATA[2..3]转子转速单位 rpm
DATA[4..5]实际输出转矩电流±10000（C620 是 ±16384）
DATA[6..7]Null没有温度字段 —— 所以屏幕上 T=0 是正常的
控制帧：0x200（ID1–4）/ 0x1FF（ID5–8），每帧 8 字节 = 4 个 int16。
反馈帧：0x200 + ID（ID=5 → 0x205）。
代码里 UserMotor = MOTOR_ID_5 → 所以电调要设 ID = 5（绿灯每秒闪 5 次）。

7. 下次进实验室按这个顺序（10 分钟）

  1. 把 C 板 DBUS 那个 3 针插头拔下来，看清它是竖着还是横着插的
  2. 竖着重插（跨 A/B/C 三排），接收机灯应立刻亮
  3. 灯亮了 → 对码 → 设 W.BUS + 端口 6 → 通道表 → 看 sL/sR/col
  4. 还不行 → 用万用表量：① 板子 A↔B 之间有没有 5 V ② 线是否通断（蜂鸣档）③ 接收机 +/− 之间有没有 5 V
一句话记牢：C 板那排 24 针里，A 排全是地、B 排全是 5V、C 排是信号。所以 3 针插头永远是竖着跨三排——横着插只会插到一排地上，没有任何电压。

8. 天地飞 RF206S 连接：怎么查（三步）

8.1 先看清接收机的针脚

8.2 线序对照（必须一一对应）

那根线的颜色接收机 RF206SC 板 24 针（DBUS 那一列）
红+（5 V）B8（VCC_5V_M）
灰 / 黑 / 棕−（GND）A8（PGND）
白 / 橙 / 黄S（信号）C8（DBUS 信号）
接收机上每个通道的 3 根针，顺序是从上到下 S → + → −（板子上有极小的丝印）。
C 板那一列的 3 根针，顺序是从上到下 A(GND) → B(5V) → C(信号)。
两边顺序是相反的，所以这类线出厂时线序就是交叉的——不要自己按顺序对插，按上表颜色对。

8.3 三步查法

第 1 步：只看，不用工具（30 秒）

看什么正确错了会怎样
C 板那端插头的方向竖着跨 A/B/C 三排横着插 = 只插到一排地，接收机没电
位置最靠近丝印 DBUS 字母的那一列（C8）插到别的列 = 信号走的是 PWM 引脚，收不到串行数据
接收机那端插在标号 6 的那一列（最右），竖着插在 1~5 = 通道 6 的 W.BUS 输出没接上
插头间距C 板是 1.25 mm，插头必须也是 1.25 mm2.54 mm 头硬插：看着到位，中间的 5V 针没接触

第 2 步：万用表通断档（2 分钟，最能定位）

拔下两端，直接量这根线：

表笔 A表笔 B应该说明
C 板端红线的针接收机端 + 针响5V 通路
C 板端灰/黑线的针接收机端 − 针响GND 通路
C 板端白线的针接收机端 S 针响信号通路
红 ↔ 灰—不响响了就是短路（会烧接收机）

第 3 步：万用表直流电压档（3 分钟，定生死）

量哪里怎么量正常值不正常说明
C 板 DBUS 三针红笔戳 B8，黑笔戳 A8≈5 V0 V → 5V 那路没起来（查是不是插在 24V OUT）
接收机 + 与 −插好后量同一列的上两根≈5 V板子有 5 V 而这里没有 → 线/间距问题
接收机 S 与 −静止时量1~3 V 的抖动值恒定 0 或 5 V → 没在输出串行数据（没对码/不是 W.BUS）

# 阶段 6：电机调试（七步，核心）

> 目标：先"看得见"（读回传），再"转得动"（按指令转），最后"转得稳"（调 PID）。
> **每一步都要先确认上一步成立。**

## ★ 先决定走哪条路（二选一，别混）

| 路线 | 电调 ID | 用哪个对象 | 要改代码吗 | 适合 |
|---|---|---|---|---|
| **A. 免改代码**（推荐先走） | **1** | `CMFL`（底盘左前轮）| ❌ 不用 | 第一次转、验证方向 |
| B. 用 UserMotor | **5** | `UserMotor` | ✅ 加一行 `SetTargetSpeed` | 后面带机构 |

走 **A** 时：遥控器 **SB 上档**（`sLeft == UP_POS`）→ 轻推右摇杆，`CtrlHandle` 自动调 `ChassisSetVelocity`，`CMFL` 就会收到目标速度。
走 **B** 时：电调设 5，`UserHandle()` 里临时加 `UserMotor.SetTargetSpeed(5);`。

## 6.1 接线（三相线不接！）

```
电池 → 电池架 XT60 → C 板 24V IN → C 板 24V OUT → C620 XT30
C620 7-Pin ──► 电机 7-Pin          （编码器，必接）
C620 CAN   ──► C 板 CAN1（2 针）    Pin1=CAN_L(黑)  Pin2=CAN_H(红)
三相线：✂ 先不接
```

- [ ] 三条都接好，三相线空着
- [ ] 万用表测 C620 的 XT30 正负极 → 不响

## 6.2 设电调 ID（这一步错了后面全白做）

- [ ] 上电（电调灯亮）
- [ ] 按一下 `SET` → 进入独立设置模式（指示灯熄灭）
- [ ] 再**短按 5 次** → 自动保存并重启
- [ ] 断电重上，**绿灯 1 秒闪 5 次** = ID 5

**为什么是 5**：代码里 `Motor UserMotor(MOTOR_ID_5, ...)` 已经定义了 5 号；ID5-8 走 `0x1FF` 帧。
（也可以设成 **1** 用 `CMFL`——底盘左前轮，那样**不用改任何代码**，见 6.5 的免改代码路线。）

| 电调灯 | 意思 |
|---|---|
| 绿灯 1 秒闪 N 次 | ID = N |
| 橙灯 1 秒闪 2 次 | 总线上 ID 冲突 |
| **红灯 1 秒闪 2 次** | 三相线未接（**现在就该是这样**）|
| 全灭 | 没供电 |

## 6.3 读回传（不需要转，最安全）

- [ ] 加上 `spd/amp/tmp/ang` 四行打印并烧录
- [ ] 用手慢慢转电机轴

**预期**：

| 字段 | 正常表现 |
|---|---|
| `tmp` | 30~40（有数就说明帧收到了）|
| `spd` | 正转正、反转负；越快数值越大 |
| `ang` | 缓慢增加；手转转子 1 圈约走 18.75° |
| `amp` | 0（没给指令）|

**判定表**：

| 现象 | 原因 |
|---|---|
| 四个数全 0 | CAN 没通 / ID 错 / 电调没供电 |
| `tmp` 有数，`spd` 不动 | **7-Pin 没接好**（编码器）|
| `spd` 有数但符号和你转的方向相反 | 不要紧，记下来，后面一起翻符号 |

## 6.4 第一次转（5 rpm，慢到吓不着人）

先确认电机**被夹住/固定在车架上**，再给指令。

- [ ] 起点：`outputMax` 先改小到 **6000**（≈7.3 A），别一上来就 16384
- [ ] 给 **输出轴 5 rpm**（= 转子 96 rpm）

**免改代码路线（推荐先试这个）**：
> 把电调 ID 设成 **1**（对应 `CMFL` 左前轮）→ 遥控器 SB 拨到**上档**（`sLeft == UP_POS`）→ 轻推右摇杆
> `CtrlHandle` 里 `UP_POS` 分支已经在调 `ChassisSetVelocity(right_col*3.0, …)`，**一行代码都不用改**。

**改代码路线**：在 `UserHandle()` 里临时加 `UserMotor.SetTargetSpeed(5);`（ID 必须设 5）。

**预期**：电机缓慢匀转，`spd` 显示 ≈5.0，`amp` 几百到一两千；松手/拨 SC 下档能停。

| 现象 | 原因 | 处理 |
|---|---|---|
| 不动，但 `amp` 有数 | 三相线没接（或接错顺序）| 接上三相线，同色对接 |
| 不动，`amp`=0 | 没调 `SetTargetSpeed`（`stopFlag` 还是 1）/ ID 不匹配 | 检查代码/ID |
| 猛转（像飞车）| 单位错（把转子 RPM 当输出轴给了）/ kp 太大 | 立刻 SC 下档，回来改 |
| 抖动、啸叫 | kp 太大或 kd 太大 | 降 kp |
| 反转 | 相线顺序反 | **任意交换两根相线**（推荐，反馈会跟着反，逻辑最干净）|

## 6.5 阶跃测试（0 → 100 rpm，看"转得稳"）

- [ ] 给 100 rpm 输出轴（= 转子 1920），观察 `spd` 曲线

**合格判据**：

1. 1 秒内稳定到 100 ± 10
2. 超调 < 20%（冲到 120 以内）
3. **用手轻按电机轴加阻力**，`spd` 掉了之后能**回到 100 附近** ← 这条证明 I 在起作用

**不合格的调法（顺序不能反）**：

| 现象 | 改什么 |
|---|---|
| 稳在上不去（比如停在 60）| 这是静差 → 需要 I：`ki = 0.5`，**同时** `componentKiMax = 6000` |
| 冲过头再回来很慢 | `ki` 太大 → 减到 0.2；或加 `kd = 0.05` |
| 抖动/高频振荡 | `kp` 太大（现在 60，试 30）或 `kd` 太大 |
| 反应太慢、软 | `kp` 加大（60 → 90）|

> **两个必须一起改**：`ki` 和 `componentKiMax`。只改 `ki` 不改 `componentKiMax`（默认 0）→ 积分被压成 0，等于没加 I。
> 框架的积分不乘 dt，所以 `ki` 量级是 **0.1 ~ 1.0**，不是 10。

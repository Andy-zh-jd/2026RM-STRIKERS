## 今晚的三条"过关"标准

1. 改一行代码 → 烧进去 → 屏幕上的内容真的变了
2. 电池供电时板子稳定跑，串口 `vbat=` 有合理读数
3. 拨遥控器开关、推杆 → 串口数字跟着变

做到这三条就可以收工，**不要碰电机三相线**。

## 阶段 1：只插 USB（零风险）

- [ ] C 板 micro USB → 电脑
- [ ] 看灯：RGB 在缓慢变色
- [ ] 终端：`python "F:\Program Files\交龙校内赛\tools\read_serial.py"`

**预期**：每 100 ms 滚一行 `gx=… az=… vbat=…`，数字有轻微抖动。

**不对怎么办**

| 现象 | 处理 |
|---|---|
| 灯不变色 | 换一根**数据线**；换 USB 口 |
| 电脑没串口 | 设备管理器里要有 `STM32 Virtual ComPort` |
| 有串口但没数据 | 固件没跑起来 → 先做阶段 2 烧录 |

## 阶段 2：烧录（验证"改→编→烧→看"闭环）

- [ ] VS Code 打开 `01_firmware\RM2027_School_Comp_Frame`
- [ ] 把 `UserTask.cpp` 里 `"gx="` 改成 `"GX="`
- [ ] `Ctrl+Shift+B` → 等到 `FLASH: 468xx B`
- [ ] `pyocd flash -t stm32f407ighx build\RM_Frame_C.hex`
- [ ] 串口里那个字变成 `GX=`

**不对怎么办**：`No available debug probes` → ST-Link 驱动/换口；`no target` → SWD 四针（**3.3V 不是 5V**）。

## 阶段 3：第一次接动力（电池）

- [ ] **先测**：万用表蜂鸣档，测电池架 XT60 正负极 → **不响**（响=短路，别上电）
- [ ] 电池装进电池架 → 输出 XT60 →（XT30 转接）→ C 板 **24V IN**
- [ ] **先不开**电池架开关，检查一遍接线
- [ ] 开电池架开关 + 长按电池开机

**预期**：灯继续变色；串口 `vbat=` 有读数（约 20~26）。

- [ ] **顺手校准**：用万用表量电池实际电压，记下两个数（万用表 = 真实值，`vbat` = 代码算的）
      → 两者差多少，就是 `vccBat` 那个换算系数的误差，回头改 `Device.cpp:153`

**不对怎么办**：`vbat` 一直是 0 → 查 ADC/分压；板子反复重启 → 喂狗（已修，理论上不会）、供电不够。

## 阶段 4：加打印（为遥控器做准备）

在 `UserHandle()` 的打印段加三行：

```c
AppendF2(" sL=", (float)RemoteControl::rcInfo.sLeft);   // 上97 中0 下158
AppendF2(" sR=", (float)RemoteControl::rcInfo.sRight);
AppendF2(" col=", RemoteControl::rcInfo.right_col);     // -1 ~ 1
```

- [ ] 编译烧录成功，串口行变长

## 阶段 5：遥控器（今晚重点）

- [ ] 接收机 DBUS 线 → C 板 **DBUS** 口
- [ ] 遥控器开机（忽略油门报警）→ 设置菜单 → 通信设置 → **对码**（长按接收机 SET 到灯闪）
- [ ] 确认 **PPM/W.BUS = W.BUS**、接收机**端口 6 = W.BUS**
- [ ] 通道设置按 `documents\remotetask.md` 的表配（副翼J1/升降J3/油门J2/方向J4/起落架SB/辅助1SC）

**预期**：接收机灯常亮；串口 `sL=`/`sR=` 数值随开关变化（上97 中0 下158）；`col=` 随右摇杆上下变化。

- [ ] 记录：SC 拨到**下档**时 `sR=158`（这是急停档）

**不对怎么办**：完全没数据 → 查 USART3 波特率 100000、DBUS 线序、接收机是不是 W.BUS 模式；数据不变 → 对码失败。

## 阶段 6（可选，需要动线）：单电机读回传

- [ ] C620 XT30 ← C 板 **24V OUT**（单电机空载够用）
- [ ] C620 **7-Pin** ↔ 电机 7-Pin
- [ ] C620 CAN → C 板 **CAN1**（2 针）：黑=CAN_L(1) 红=CAN_H(2)
- [ ] **三相动力线不接**
- [ ] 电调设 ID=5（按 SET 进设置，短按 5 次），断电重上，**绿灯 1 秒闪 5 次**
- [ ] 加四行打印：`spd=` `amp=` `tmp=` `ang=`

**预期**：`tmp` 有 30 多度；手转电机轴，`spd` 正负变化、`ang` 缓慢增加；C620 红灯 1 秒闪 2 次（三相线未接，正常）。

**不对怎么办**：全 0 → ID/CAN 线序/1 Mbps；`spd` 不动但 `tmp` 有数 → 7-Pin 没接好。

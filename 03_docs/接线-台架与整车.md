# 接线：台架（只读电机反馈）→ 整车

> 依据：`RoboMaster 开发板 C 型用户手册`、`C620 使用说明`、`remotetask.md`。
> 原则：**先只用一块电池、一根 CAN、一个电调，确认能读到数，再上整车。**

## 台架六步（不需要夹具，电机物理上转不起来）

```
   电池 XT30 ──► C 板 24V IN ──► C 板 24V OUT ──► C620 XT30
                                    │
   PC ◄── micro USB ── C 板         │
                                    ├── CAN1(2pin) ──► C620 CAN 口
                                    │      Pin1 = CAN_L(黑)   Pin2 = CAN_H(红)
                                    └── （三相动力线不接！）
   M3508 ◄── 7-Pin 编码器线 ──► C620 7-Pin 口
```

1. **电池 → C 板 24V IN**（XT30，支持 8–28 V，有防反接 + 缓启动；>28 V 会自动关断）
2. **C 板 24V OUT → C620 的 XT30**（单电机空载没几个安培，够用）
3. **C620 7-Pin ↔ 电机 7-Pin**：编码器线，防插反，只有一个方向。**7-Pin 必须接**，电调靠它读转子位置
4. **C620 CAN 口 → C 板 CAN1**（2-pin）：`Pin1 = CAN_L（黑）`、`Pin2 = CAN_H（红）`
5. **三相动力线拔掉**（只留 7-Pin + CAN + 24V）→ 电机物理上不可能转
6. **给电调设 ID = 5**：通电后按一次 `SET` 进独立设置模式，再短按 **5 次** → 断电重上，绿灯每秒闪 5 次就是 ID=5

> 为什么是 5：代码里 `Motor UserMotor(MOTOR_ID_5, ...)`，ID 5 对应 **CAN1 / 0x1FF** 那一帧。

### 你会看到什么

- 串口每 100 ms 一行：`gx=… az=… vbat=…`，手转电机轴时 `angle/speed` 应该变
- C620 **红灯每 1 秒闪 2 次 = “三相线未接入”**，这是提示不是故障（我们故意拔的）
- 如果完全读不到反馈：① 先查 ID 和 1 Mbps；② 把三相线接回来、电机夹住再试；③ 最后才怀疑终端电阻

## 整车（第二阶段，别提前跳）

| 链路 | 接法 | 注意 |
|---|---|---|
| 供电 | 电池 → **裁判系统模块** → 分电/中心板2 → C 板 + 4×C620 | **规则硬要求**，检录会查"是否从裁判系统输出端取电" |
| CAN | C 板 CAN1 → 中心板2 CAN 分发 → 各 C620 | 底盘电调 ID 1–4（0x200 帧），机构 ID 5–8（0x1FF 帧）|
| 终端电阻 | C620 上的 120Ω 开关，**只开总线两端**的两个 | 台架短线上没开也能跑；整车才需要 |
| 遥控 | 接收机 → C 板 **DBUS** 口（丝印 DBUS，与 PWM 共用一个连接器）| 接收机端口 6 设 W.BUS，DBUS 100 kbps |
| 烧录 | ST-Link → C 板 **SWD**（J8 4-pin）：①SWDIO ②SWCLK ③GND ④3.3V | **3.3V，别接 5V，会烧板** |
| 打印 | C 板 **micro USB** → PC | 不是 Type-C；Type-C 是裁判系统上的检录口 |

## 三个容易烧东西/白查的点

1. **USB 供电只能驱动 STM32 和部分板载外设**（手册明确写），PWM 那一路不吃 USB 的电 → 测舵机/电机必须上电池
2. **C 板 24V OUT 不是给整车 20A 用的**，整车一定走中心板2/分电板；台架单电机才用它
3. **CAN_L/CAN_H 接反不会烧**，但会一条数据都收不到，而且报错像"电调没上电"——先量 CAN 线序

### 踩过的坑（写进肌肉记忆）

1. **烧录时串口句柄会失效**：`pyocd flash` 会复位板子 → USB 重新枚举 → 正在跑的串口脚本报 `ClearCommError failed (PermissionError 13)`。
   **规矩：烧录前先关掉读串口的窗口；烧完等 2 秒再开。**
2. 卡住的 python 进程会一直占着 COM5（`拒绝访问`）→ `Get-Process python | Stop-Process`。
3. DBUS 的 5 V 来自 **24 V 降压**（`VCC_5V_M`），**USB 供电带不动** → 接收机必须等 24 V 上电才可能有电。
4. C610 没有温度字段，**别用 `T=0` 判断“没通”**；要看 `ang`/`rpm`。

## 2026-10-20 深夜追加 · USB 打不开的根因（已定位）

**现象**：C 板 USB 能枚举（`USB 串行设备 (COM5)`，PnP 状态 OK），但打开永远报
`Cannot configure port, OSError 22 参数错误`；换线、换口、拔 24V、关终端都无效。

**定位过程**：烧了一个跳过 IMU SPI 读的最小固件（`DBG_MINIMAL 1`）→ **串口立刻正常**。
把 IMU 加回来 → 立刻复现。→ **根因是 IMU 的 SPI 读**。

**为什么缩短超时（100ms→1ms）也没用**：
`HAL_SPI_TransmitReceive(..., Timeout)` 内部用 `HAL_GetTick()` 判超时。
但这段代码跑在 **TIM10 的 1ms 中断**里，而 SysTick 优先级低于它 → **tick 不再递增**
→ `(HAL_GetTick() - Tickstart) > Timeout` 永远不成立 → **死循环**（超时机制整体失效）。
结果 1ms 中断回不来，USB 控制传输彻底没机会响应 → 设备在、口打不开。

**临时办法**：`DBG_MINIMAL 1` —— 不读 IMU，其余（CAN/电机/遥控/打印）全部正常。

**待办**：
1. SPI 读改成**计数器超时**（不依赖 HAL_GetTick），或把 SysTick 优先级提到 TIM10 之上
2. IMU 本身要单独特查：读一次 chip id（0x1E / 0x0F）就能判断 BMI088 是否还活着
3. C 板 24V IN 当时没接（`vbat=4.10`），但电调有电（`ang=4.35` 有数）→ 说明 24V 只接到了电调侧

## 2026-10-20 深夜 · 遥控器打通（M1 达成）

**关键认知**：之前接收机不亮，**是因为当时板上只有 USB 供电**（`vbat=4.10`），DBUS 的 5V 来自
24V 降压（VCC_5V_M）。**接上 24V 后接收机立刻亮灯** → 不是线的问题、也不是口的问题。

**对码后实测**（DBG_MINIMAL 模式下）：

```
sL=158  sR=97  col=-0.01     ← DBUS 帧正常到达！
```

- `sL=158` = SB 在下档（DOWN_POS）
- `sR=97`  = SC 在上档（UP_POS）
- `col=-0.01` = 右摇杆在中位

**档位枚举**：UP=97 / MID=0 / DOWN=158；**SC 拨到下档（158）= 急停**。

**教训汇总（今晚 5 条）**：
1. USB 能枚举但打不开 → 先怀疑固件里有阻塞调用（本次是 SPI 读 IMU），不是线/口/电源
2. `HAL_*_Transmit` 的超时靠 `HAL_GetTick()`，在中断里 tick 不涨 → **超时永不触发 → 死循环**
3. DBUS 的 5V 来自 24V 降压，**只有 USB 时接收机不可能亮**
4. 烧录前先关串口窗口（否则 `ClearCommError`）
5. 没有万用表时，大部分供电问题只能靠"换线/换口/加 24V"这类排除法

## 2026-10-21 下午 · M2 完成：单电机按遥控指令转

**实测证据**（6 秒采集）：

| 字段 | 范围 | 说明 |
|---|---|---|
| `col` | −1.02 ~ 0.99 | 摇杆模拟量正常 |
| `tgt` | −22.48 ~ +20.70 | 目标跟着摇杆走 |
| `rpm` | −13.86 ~ +14.33 | **电机真的转了，方向随目标** |
| `cur` | −461 ~ +407 | 电流约 0.46 A（C610 满量程 10000）|
| `stop` | 0 | 输出已解锁（摇杆给指令）|
| `sL / sR` | 0 / 97 | SB 中档、SC 上档（非急停）|

**注意有静差**：`tgt=20.7` 时 `rpm` 只到 14.3 —— 因为 `ki=0`（纯 P）。要消静差后续加 `ki≈0.5` + `componentKiMax≈6000`。

**同日修复的第二个安全 bug**：
没接接收机时 `rcInfo` 零初始化 → `sLeft = 0` 恰好等于 `MID_POS` → `CtrlHandle` 误判
"用户选了中档" → `UserSetSpeed(0)` 解开 `stopFlag`（实测 `stop` 从 1 变 0）。
修法：新增 `RemoteAlive()`（100ms 内无合法 DBUS 帧即判离线），`CtrlHandle` 开头强制进安全态。

**同日第三处修复**：`SysTick` 优先级提到 0（修 HAL 超时在中断内失效导致死循环）；
SPI 超时 100ms→1ms + 连续失败 5 次熔断。带 IMU 的版本仍会卡死 → **疑似 BMI088 硬件问题**，
暂用 `DBG_MINIMAL 1`（不读 IMU）运行，待单独特查。

**当前固件打印格式**（已改成四轮）：
```
gx=.. gy=.. gz=.. ax=.. ay=.. az=.. vbat=..
r1=.. r2=.. r3=.. r4=.. tgt=.. stop=.. sL=.. sR=.. col=..
```
`r1~r4` = CMFL/CMFR/CMBL/CMBR（ID1~4）的输出轴转速。

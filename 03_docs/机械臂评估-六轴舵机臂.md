# 机械臂评估：248 元六轴舵机臂，能夹住矿石吗？

看到的东西：6 自由度舵机机械臂（PWM 舵机 + 小舵机夹爪 + 亚克力/铝板结构），¥248 起，可开票。
下面按"能不能用、能不能赢"两件事拆开说。

## 一、先说结论

| 问题 | 结论 |
|---|---|
| 能夹住石头吗？ | **能做原型，不能当比赛主力夹爪** |
| 要不要再买一个？ | **不要买第二个整臂**。钱花在供电和备用舵机上 |
| 正式方案用什么？ | 官方发的 **M2006（1 N·m，36:1）+ 自制夹爪**，舵机臂留作原型/演示/备份 |

## 二、为什么"能夹但不够"

### 1. 抓取方式比夹紧力更重要（这是最值得改的设计）

规则给的矿石是：**边长 120 mm 立方体，顶面开 Ø95 × 深 70 mm 的凹槽**。

那个凹槽不是装饰，是**给你的抓取接口**。所以：

- ❌ 靠两侧摩擦夹紧 → 需要大力，且 120 mm 的方块重心如果偏，一抖就掉
- ✅ **插进凹槽"撑住"或"勾住"** → 只需要很小的力，靠几何形状承重，抖不掉

舵机夹爪的力气本来就小，**改成内撑式/钩式，能立刻把"夹得住"从"看运气"变成"看结构"**。

### 2. 力矩账（用静态估算，1 kg·cm ≈ 0.098 N·m）

假设：臂自重 400 g、重心离肩 120 mm；矿石+夹爪 300 g、抓取点离肩 250 mm。

```
肩关节静态力矩 = 0.4×9.81×0.12 + 0.3×9.81×0.25 ≈ 1.2 N·m
```

| 舵机型号（常见） | 堵转力矩 | 够不够 |
|---|---|---|
| MG996R 类（11 kg·cm @6V） | ≈ 1.08 N·m | ❌ 不够，会慢慢垂下去 |
| 25 kg·cm 级（DS3218 等） | ≈ 2.45 N·m | ⚠️ 勉强（2 倍余量，动起来就没了）|

**而且这还是静态**。上 20 cm 台阶时整车受冲击，动态载荷要按 2–3 倍算 → 舵机臂会打齿。

### 3. 真正致命的不是力气，是供电

C 板 7 路 PWM 接口：**共用 5 V，总输出 5 A**（手册明确）。6 个舵机每个堵转 2–3 A：

- 一起动 → 峰值十几安 → **5 V 被拉垮**
- 结果：舵机抖、板子复位、串口重连，你会以为是"代码有 bug"

**必须**：24 V → 外接 UBEC（6 V 或 7.4 V，≥10 A）给舵机供电，**信号线接 C 板 PWM，电源从 UBEC 走，两地共地**，再并一个 1000 µF 电解电容抗瞬时跌落。

### 4. 速度反而不是问题

一场比赛是 **7 分钟**（规则 5.4.4）。舵机抓一次 3–4 秒完全够用，别被"舵机慢"劝退——瓶颈在力气、供电、可靠性，不在速度。

## 三、比赛视角的三个检录红线

| 规则 | 你要做什么 |
|---|---|
| 初始尺寸 ≤ 600×600×500，变形后 ≤ 800×600×700 mm | 臂伸出别超；量出来贴着数据设计 |
| **变形伸展机构必须有机械限位，不能只有电控限位** | `Servo` 类里的 `angleLimit_Min/Max` 是软件限位，**不够**，必须加硬挡块 |
| 电机/舵机要做好保护，防撞击损坏 | 收起姿态 + 护板；上台阶时先收臂 |

## 四、要不要再买？钱花在哪

**别买第二个整臂**（¥248 买来还是同一个问题）。按优先级买这三样：

| 买什么 | 大约价格 | 为什么 |
|---|---|---|
| **UBEC 24 V→6 V/7.4 V，≥10 A** | ¥30–60 | 不买这个，舵机一动板子就复位，所有调试白做 |
| **备用舵机 ×2（同型号 25 kg·cm）** | ¥20–30/个 | 打齿是必然事件，不是意外 |
| 大电流分电线 + 1000 µF 电容 + XT30 转接 | ¥30 | 抗瞬时电流、接线清爽 |

## 五、建议的分工

| 用途 | 用什么 |
|---|---|
| **比赛主力夹爪** | M2006（官方物资，1 N·m，36:1）+ 自制二指/四连杆夹爪 + **内撑式抓头** + 机械限位 |
| 舵机臂 | 抓取动作原型、训练操作手、演示、备份；**不用它上场比赛** |

为什么 M2006 更合适：扭矩是舵机的 2–4 倍、CAN 闭环（知道转到哪了）、官方发放（检录不找麻烦）、金属齿轮耐冲击。

## 六、现在就能做的三件事（半小时）

1. **称矿石**（或问组委会）—— 这个数决定一切。规则里没写重量，是我们现在最大的信息缺口
2. **空载测臂的末端能力**：让臂水平伸出 250 mm，末端挂矿泉水（≈500 g）看能不能停住、会不会抖
3. **让关节动起来**：框架里已有 `Servo` 类（`SERVO_ID_1~7`，`POSITION_180`/`SPEED_360`），
   `Servo 夹爪(&init); ... 夹爪.SetTargetAngle(120);` 就能试——顺便验证 UBEC 供电方案

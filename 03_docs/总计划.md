# 总计划（2026-10-20 → 11-21）

> 一句话：**先让车听人话（底盘），再让它上台阶（垂直通过），最后把三级矿集齐（奇观）。**
> 所有"时间"都不写小时数，只写**闸门**：判据过了才往下走，过不了就砍功能。

## 0. 目标分三层

| 层 | 目标 | 判据 |
|---|---|---|
| 保底 | 底盘听遥控走 + 抓一颗矿 | 走 2 m 偏 <10 cm；抓取 10 次成功 8 次 |
| 现实 | 上一级（20 cm）+ 一级/三级各放一颗 + 完整演示"抓→走→放" | 能在真实场地跑完一轮不摔机、不断电 |
| 冲刺 | **奇观**：一、二、三级各一颗（需要 35 cm 也上去） | 1 分钟内集齐三级 |

## 2. 里程碑（每个都是"闸门"）

| 里程碑 | 内容 | 通过判据 | 依赖 |
|---|---|---|---|
| **M0** 闭环 | 改代码→编译→烧录→看串口 | 改一个字能看到变化 | — |
| **M1** 遥控通 | 对码 + 打印 rcInfo | 拨档位/推杆，`sL/sR/col` 跟着变；SC 下档 = 158 | 接收机 |
| **M2** 单电机通 | 读回传 → 5 rpm → 100 rpm | 手转轴 `spd/ang` 变；100 rpm 1 s 内稳、超调 <20%、加阻力能回 | M1 或 免改代码路线 |
| **M3** 四轮走 | 4 个 ID + 方向 + 逆解 | 垫起四轮同向；落地走 2 m 偏 <10 cm；SC 下档真停 | M2 |
| **M4** 能抓 | 夹爪 + 档位 + 保护 | 抓 120 mm 矿石 10 次成功 ≥8；急停能断电 | 机械结构 |
| **M5** 上台阶 | 20 cm（走坡）+ 15 cm（一级→二级） | 一级 100% 成功；二级冲坡 10 次 ≥5 次；**上台阶瞬间不复位** | M3 + 限流/重心 |
| **M6** 能打 | 7 分钟整场 + 检录 | 完整跑一轮：抓→上一级放→回地面→中央放三级；检录项全过 | M4 + M5 |

## 4. 砍功能红线（提前写好，别临场犹豫）

| 如果 | 那就 |
|---|---|
| 10/26 车还不能听遥控走 | 砍掉机构，只做"底盘 + 推/铲"；目标降为不垫底 |
| 11/2 一级台阶上不去 | 放弃上台阶，改打**地面 + 干扰**（推对方已放的矿石），只拿一级/三级 |
| 11/9 二级上不去 | 放弃奇观，转"分数最大化"：拼命堆一、三级矿 + 防守 |
| 11/9 整车 7 分钟还跑不完一轮 | 冻结所有功能，只保"能动 + 能抓一次" |
| 任何时刻出现"上电复位" | **优先修供电，不修功能**（复位比少一个功能致命）|

## 5. 三条线（人少也要分，各有一份清单）

| 线 | 负责 | 交付物 |

| **操作 + 规则 + 检录**（两人一起）| 操作手训练、检录清单、场地路线、申诉取证 | 一页"场地路线图"、一页检录自查表 |

## 6. 热身赛要测的 5 件事（提前写好）

1. 23° 坡和 11° 隧道到底好不好走（是不是唯一上台阶路径）
2. 一级 → 二级那 15 cm，冲坡成功率多少
3. 矿石实际重量和凹槽深度（决定夹爪方案）
4. 中央基地的争抢位置怎么卡位
5. 7 分钟里我们实际能搬几颗

## 7. 风险台账

| 风险 | 影响 | 对策 |
|---|---|---|
| Parallels 试用 **10/27 到期** | Mac 那台 Keil 环境停摆 | 代码以本仓库为准；GCC 链随时可用 |
| **矿石重量未知**（规则没写） | 夹爪力矩/方案全悬空 | 尽快称实物或问组委会 |
| 只有 **1 块 C 板** | 坏了就停摆 | 不拆不焊；SWD 只接 3.3V |
| 电池架持续 **35 A** 上限 | 爬坡 56 A 会压降 | 限流 12000/16384 + 助跑；别长时间满载 |
| 裁判系统模块还没到手/参数未知 | 供电链无法定稿 | W3 前必须拿到；先按"电池→裁判系统→分配"预留空间 |
| 检录项（尺寸/重量/麦轮晃动/电池架螺丝）| 直接失去资格 | W3 做一次完整预检 |

1. 打开 [实验室操作清单.md](实验室操作清单.md)，按阶段做，不跳步

3. 收工：关电池架开关 + 电池关机 → `git commit` 一行 → 拍接线照 → 写三个问题

## 对方（有推送权限的人）怎么用

在仓库目录下执行一条命令，就能把我们这边的全部历史与代码拉进去：

```bash
git bundle verify 2026RM-STRIKERS-full.bundle     # 先校验
git pull 2026RM-STRIKERS-full.bundle main          # 拉进当前仓库（会合并历史）
git push origin main
```

或者单独 clone 出来看：

```bash
git clone 2026RM-STRIKERS-full.bundle RM2027-check
```
